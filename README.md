# Clip-Cam
Clip cam is a compact, lightweight camera designed to easily clip/attach onto clothing to enable for videos to be recorded.

##### Features
  - Lightweight, compact design
  - 1080p 30fps recording
  - 32 gb storage (larger micro-SD cards can be swapped in)
  - Up to 8 hours of battery life

##### Technical Specifications
  - 3000 mAH battery

##### Background Info
Clip-cam was created to be my first hardware project and be both practical and educational. The concept of a clip-on camera originated from my interests in track-and field alongside soccer from which performance can be analysed in depth based on a recording playback. Additionally, the project was created with applications with regards to content creation alongside general recreation, allowing for experiences to be shared in a more intimate manner.
